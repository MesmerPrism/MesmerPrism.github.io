2. Connect Quest by USB

Use a USB data cable with your Android phone as the USB host. Keep Quest awake and on the same Wi-Fi network as the PC.

Quest needs Developer Mode and USB debugging. Your phone needs neither Developer Options nor an APK.

  1. Choose Quest in the USB prompt.
  2. In Quest, allow the phone’s USB debugging key.
  3. In Quest, allow the PC’s debugging key if asked.

Install or troubleshoot

Installation is optional. This page works directly in Android Chrome. To install, use Chrome’s menu → Add to Home screen or Install app.

After opening the installed app without a pairing, scan the PC’s QR code again or paste its current link here. Your browser decides whether a scanned link opens the installed app or Chrome.

If local network access is blocked, allow it for this site in Chrome, then choose Reconnect to Fleet. Check the PC firewall, Wi-Fi client isolation and any VPN if the PC is unreachable.

Pair only with a PC and network you trust. The hub may use local HTTP; the token and device details then travel unencrypted on that local network. No token, key or Quest data is uploaded to this public website.

The browser keeps a local ADB key for future Quest approval. Pairing credentials stay in this window’s session. Forget this pairing clears them; use Quest’s debugging settings to revoke trusted debugging keys.
