Stable by default. Labs by explicit choice.

This catalog explains channel identity and transition policy. It does not publish binaries and does not assert that a release exists. Download links appear only after an owning product workflow supplies validated, immutable release metadata.

Default: stable. Labs is an explicit opt-in product channel. Its release maturity is reported separately as alpha, beta, release candidate, or released. Confirm the product channel, maturity, version, source revision, artifact SHA-256, and installation identity before opting in.

Useful, public-safe feedback

Use the product-specific link above. Include these six facts:

  • product channel, maturity, and exact version;
  • 40-hex source revision;
  • 64-hex artifact SHA-256;
  • operating system and version;
  • device class, such as “Windows desktop” or “Quest headset”;
  • a minimal description and reproducible steps.
Keep reports public-safe. Do not include credentials, personal data, device serials, network addresses, pairing material, private logs, screenshots containing personal information, or proprietary payloads.

Where release authority lives

Each product owner creates and signs its own release metadata and immutable GitHub release URLs. This page only projects owner-validated facts.
